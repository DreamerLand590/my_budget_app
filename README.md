# Звіт про витрати домашнього бюджету

Невелика навчальна програма (заняття 5, AI Programming in Python). 
Вона читає файл data/expenses.csv, пропускає рядки з помилками і рахує загальну суму витрат, а також розподіляє витрати за категоріями. Дані навчальні, вигадані.

## Як запустити

`bash
python main.py

Потрібен лише Python 3.10 або новіший. Сторонні бібліотеки не використовуються.


Звіт про витрати домашнього бюджету
-----------------------------------
Загальна сума витрат: 2910.00 грн

Витрати за категоріями:
Аптека           350.00 грн
Комуналка       1200.00 грн
Продукти        1050.00 грн
Розваги          200.00 грн
Транспорт        110.00 грн

Найбільше грошей пішло на: Комуналка

Попередження (пропущені рядки):
 - рядок 5: amount не число: '', пропущено
 - рядок 7: amount не число: 'текст_замість_числа', пропущено
 - рядок 9: від'ємна сума витрат: -500.0, пропущено

Програма також друкує попередження про пропущені рядки і зберігає звіт у output/report.txt.

Структура

my_budget/
├── main.py               # точка входу: з'єднує шари і ловить помилки
├── app/                  # пакет з кодом програми
│   ├── init.py       # робить app пакетом
│   ├── config.py         # шляхи й налаштування
│   ├── models.py         # модель даних (Expense)
│   ├── data_loader.py    # шар даних: читання CSV
│   ├── services.py       # шар логіки: розрахунки
│   ├── report.py         # шар показу: текст звіту
│   └── exceptions.py     # власні винятки
├── data/                 # вхідні дані
│   └── expenses.csv
├── output/               # сюди зберігається report.txt
├── tests/                # тести
├── requirements.txt      # залежності
└── .gitignore            # що не потрапляє в Git
